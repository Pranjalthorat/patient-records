# Patient Records

A web application for managing patient blood test results. Each record stores the patient's
name, date of birth, email, glucose, haemoglobin and cholesterol. When valid data is saved,
the values are sent to the Google Gemini API, and the AI's short health remark is stored in
the **Remarks** column.

- **Backend:** Python, Flask, SQLite (standard `sqlite3` module)
- **Frontend:** HTML and CSS only (server-rendered Jinja templates, no JavaScript)
- **AI service:** Google Gemini API (`generateContent` endpoint, called with `requests`)

## Setup

```bash
pip install -r requirements.txt
copy .env.example .env        # macOS/Linux: cp .env.example .env
```

Open `.env` and set `GEMINI_API_KEY` (a free key is available at https://aistudio.google.com/apikey).
Then start the app and open http://127.0.0.1:5000:

```bash
python app.py
```

If the key is missing or the AI service is unreachable, the record is still saved and its
Remarks column shows **Prediction pending** with a **Retry prediction** button.

`GEMINI_MODEL` in `.env` selects the model. Change it if Google retires the default.


## Validation rules

| Field | Rule |
|---|---|
| Full name | At least 2 characters; letters, spaces, hyphens, apostrophes and full stops only |
| Date of birth | `dd/mm/yyyy` (`dd.mm.yyyy` and `dd-mm-yyyy` are also accepted and shown as `dd/mm/yyyy`); must be a real calendar date, not in the future, not more than 120 years ago |
| Email | Must look like `name@domain.tld`; must be unique |
| Glucose | Number, 20 to 600 mg/dL |
| Haemoglobin | Number, 3 to 25 g/dL |
| Cholesterol | Number, 50 to 600 mg/dL |
| Whole record | The same name and date of birth cannot be saved twice |

All checks run on the server so every error is shown under its field in the same way.

## Behaviour notes

- Editing a record only calls the AI again when the date of birth or a blood value changes.
  Changing just the name or email keeps the existing remarks.
- If a changed record cannot be re-predicted, the old remarks are cleared rather than left
  describing values that no longer match.
- Delete opens a confirmation page before anything is removed.
- Sex is not collected, so the AI is told to use general adult reference ranges.

## Tests

```bash
python -m unittest -v
```

Runs the 10 assignment records against a temporary database and checks which are saved and
which are rejected, plus edit, delete and AI-failure behaviour.
